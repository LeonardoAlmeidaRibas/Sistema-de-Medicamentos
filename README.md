# Sistema-de-Medicamentos
Sistema feito para prova da disciplina de Programação II, inteiramente usando Java orientado á objetos.
O sistema feito em Java é responsável por gerenciar a venda de medicamentos genéricos e de marca. Os medicamentos tem as seguintes características:
● Nome
● Valor
Apenas os medicamentos de marca devem possuir a seguinte característica adicional:
● Marca
Ao informar o valor dos medicamentos, os genéricos tem um desconto de 20% aplicado automaticamente, os de marca tem um desconto de 10% aplicado automaticamente.
O sistema também inclui uma classe que representa uma farmácia, responsável por receber todos os produtos que o cliente deseja comprar. Além disso, a farmácia tem um método responsável por retornar o valor total de todos os medicamentos (a soma de todos os genéricos e de marca).
